# Embedded Systems

A growing collection of embedded systems projects in C, covering register-level
microcontroller programming, communication protocols, and simulated hardware work.

Each project lives in its own folder with its own README describing what it does
and how to build/run it.

## Projects

- [`uart-protocol/`](./uart-protocol) — A register-level UART communication
  protocol for the STM32F103C8, including a custom framed packet format with
  checksum validation.

More projects will be added here over time.

## Toolchain

- **Language:** Embedded C
- **Target:** STM32F103C8 ("Blue Pill", ARM Cortex-M3)
- **IDE / Simulator:** Keil MDK-ARM (uVision)
